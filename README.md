Um sistema de xadrez desenvolvido em JavaFX, com interface gráfica interativa, controle de tempo, histórico de movimentos e suporte para salvar/carregar partidas.

✨ Funcionalidades
Interface gráfica com tabuleiro e peças renderizadas.

Controle de tempo individual para cada jogador.

Histórico de movimentos exibido em tempo real.

Salvar e carregar partidas para continuar jogos.

Detecção de timeout automática.
